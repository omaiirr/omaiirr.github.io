Theme Library redesign — native scenes + editing

Fixed by definition (no pick needed): clicking a scene applies it natively — the scene becomes the background directly, no custom theme is created, nothing appears in the custom-themes list in expanded settings, and picking a built-in theme cleanly returns you to it. The panel below shows the new (overhauled) chrome. What needs your pick: how editing should work — three variants below.

The redesigned library panel (new chrome, native behavior)

Hover a card → small ⚙ customize affordance (where it appears depends on the variant you pick). Active card gets the ✓ badge like the themes picker. All styling moves to the planner-v3 language: accent-bounded panel, alto labels, focus rings, springy pills.

Editing mechanics — pick a variant

Variant A — inline drawer under the grid MY RECOMMENDATION

Hover any card → ⚙ (or double-click). A drawer slides open under the grid with that scene's real options (sliders, colors — the same fields the builder's Animated Scene tab shows) + an overlay tint control. Changes apply to the live background instantly; "Done" collapses the drawer. The scene stays native (no theme created). A "Save as custom theme" secondary button turns your tweaked scene into a real theme when you ever want that.

Variant B — edit in the existing theme builder

⚙ on a card hands the scene to the current theme editor (Animated Scene tab) pre-loaded with that scene, in "session" mode: tweaks preview live, but only become persistent if you press "Save as custom theme" — otherwise nothing is stored. Familiar UI (it already exists), but you leave the library modal, and "just tweak speed" becomes a 5-step journey.

Variant C — minimal popover per control

⚙ opens a tiny popover with just bg color + overlay tint (no per-scene options). Lightest build, but you can't actually tune the scenes (speed, counts, colors) — which is most of the point.

All variants keep: search, filters (All/Simple/Calm/Dramatic), thumbnails, hover previews, ✓ active badge, and the "Open theme library (40)" buttons where they are.
